# tp-collaboration-2

Mini projet web réalisé en binôme pour s'exercer au travail collaboratif avec Git et GitHub.

## Contenu

- login.html : page de connexion (Étudiant A)
- register.html : page d'inscription (Étudiant B)

## Workflow

1. Étudiant A crée le repository et invite Étudiant B comme collaborateur.
2. Étudiant B crée la branche feature-register et ajoute register.html.
3. Étudiant B ouvre une Pull Request vers main.
4. Étudiant A vérifie le code, commente si nécessaire et fait le merge.
